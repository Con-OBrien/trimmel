How to move an installed program to another drive on Windows

Last reviewed 22 October 2026 · Windows 10 and 11

You can move an installed program to another drive without reinstalling it. Copy the folder with robocopy, then create a junction with mklink /J at the old path so Windows still finds it. Check it works, then delete the old copy.

Before you start

  • Only move programs you installed, such as games and large tools. Never move anything in C:\Windows, and avoid drivers, antivirus and anything that runs as a service.
  • Close the program completely, including its tray icon.
  • The destination must be an internal NTFS drive. If it is a USB or network drive and it is not connected at boot, the program will not start.
  • Open a terminal as administrator. Copying with the original permissions needs admin rights.

Step by step

This example moves C:\Program Files\Foo to D:\Moved Programs\Foo. Change the names to match your program.

1. Copy it, with permissions:

robocopy "C:\Program Files\Foo" "D:\Moved Programs\Foo" /E /COPY:DATSO /DCOPY:DAT /R:1 /W:1

2. Rename the original, so you still have it:

rename "C:\Program Files\Foo" Foo.old

3. Create a junction at the old path that points to the new one:

mklink /J "C:\Program Files\Foo" "D:\Moved Programs\Foo"

A junction is a folder-shaped link. Windows and the program still see C:\Program Files\Foo, but the files live on D:.

4. Start the program and check it works, including an update or a save. Only then delete Foo.old.

How to undo it

rmdir "C:\Program Files\Foo"
robocopy "D:\Moved Programs\Foo" "C:\Program Files\Foo" /E /COPY:DATSO /DCOPY:DAT
Use plain rmdir on the junction, never rmdir /s. Plain rmdir removes only the link. Adding /s on some Windows versions can delete the files it points to.

What can go wrong

  • The program updates itself and replaces the folder. Some updaters delete and recreate the install folder, which removes the junction. Check after the first update.
  • The destination drive is missing. Unplug a USB drive, or fail to mount a disk, and the program will not start until it is back.
  • Store apps are different. Apps from the Microsoft Store move through Settings, Apps, Installed apps, Advanced options, not with a junction.
  • Anti-cheat and licence checks. A few games and DRM schemes dislike paths that change. Try one game first.
