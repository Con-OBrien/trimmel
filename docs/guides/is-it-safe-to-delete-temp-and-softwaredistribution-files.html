Is it safe to delete Temp, SoftwareDistribution and Windows.old files?

Last reviewed 22 October 2026 · Windows 10 and 11

Yes for Temp, the Recycle Bin and caches. Yes for SoftwareDistribution\Download when no update is pending. Never delete WinSxS or Installer by hand.

The short list

Folder or itemSafe to clear?Notes
%TEMP% (your temp folder)YesSkip files that are in use. Windows refuses to delete locked ones. Close Office and installers first.
C:\Windows\TempYesNeeds admin rights. Same rule for files in use.
C:\Windows\SoftwareDistribution\DownloadYes, with careOnly when no update is downloading or waiting for a restart. See below.
Recycle BinYesLook first. Emptying it is permanent.
Thumbnail cache, shader caches, crash dumpsYesWindows and games rebuild them.
C:\Windows\Windows.oldYes, if you will not roll backRemove it with Disk Cleanup, "Previous Windows installation(s)". After that you cannot go back to the old Windows version.
C:\Windows\WinSxS, C:\Windows\Installer, System32NoNever delete by hand. Programs and Windows need them.

Clearing the Windows Update download folder

The Download folder holds update files Windows has already fetched. If an update is half-downloaded or installed but waiting for a restart, deleting them can make the update fail and start again. Restart first, then run this in an admin terminal:

net stop wuauserv
net stop bits
del /q /f /s "C:\Windows\SoftwareDistribution\Download\*"
net start bits
net start wuauserv

Windows downloads any update it still needs again. Leave the neighbouring DataStore folder alone unless you are fixing a broken Windows Update, because it holds your update history.

Temp files: what could go wrong

  • Open documents. Word and Excel keep files that start with ~$ while a document is open. Delete them and you can lose autosave data.
  • Installers in progress. Setup programs unpack into temp. Clear it only when nothing is installing.
  • Very new files. Only clear files older than a day. Anything fresher may belong to a running program.
