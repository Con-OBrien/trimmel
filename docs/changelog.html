Changelog

Last reviewed 22 October 2026 · Windows 10 and 11

Each release, newest first. Everything that existed before stays free.

0.2.1 22 October 2026

  • Startup now lists Microsoft Store app startup tasks and lets you switch them on and off.
  • Installing drivers shows each step (restore point, download, install) and warns you on a metered connection.
  • If setup fails part-way, it removes what it added instead of leaving a half install.
  • Uninstalling with "delete settings" now also removes the saved sign-in token from Windows Credential Manager.
  • Behind the scenes: the project is renamed throughout, and build settings use TRIMMEL_ names (the old PCOPT_ names still work).

0.2.0 22 October 2026

  • PC Optimizer is now Trimmel. Your settings and sign-in move across on first start, and setup replaces the old version.
  • New Settings page, an update check, and a modify mode in the installer.
  • Startup lists scheduled tasks too, with an impact rating and a plain-English note on each item.
  • New Storage page with suggestions, an Apps list, a health score on the Overview and a welcome guide.
  • Safety fixes from the first QA round: moves keep file permissions and refuse removable or network drives, an offline start keeps you signed in, Windows Update downloads are not cleared while a restart is pending, and cleanup keeps Office lock files.
